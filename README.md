# East York Dawn Patrol — Sunday 6:30am
Static site: free Sunday sunrise road rides from East York.

## Deploy (GitHub Pages)
1. Create a new repo (e.g., `east-york-dawn-patrol`) and add these files.
2. Push to `main` branch.
3. In **Settings → Pages**, set **Source** to "Deploy from a branch" and choose `main` / root.
4. Your site will appear at `https://<your-username>.github.io/east-york-dawn-patrol/`.

## Deploy (Netlify, Vercel, Cloudflare Pages)
- Drag & drop this folder onto Netlify or Cloudflare Pages, or connect the Git repo.
- No build step needed.

## Notes
- Images are hot‑linked from Unsplash and Pexels, which allow free use with attribution (see each service for full license).
- Map is embedded from OpenStreetMap.
- `calendar.ics` adds a recurring Sunday 06:30 event.
